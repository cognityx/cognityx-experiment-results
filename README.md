# Cognityx Experiment Results

This public repository holds compact, reviewer-friendly snapshots produced by
Cognityx Experiments. In ordinary language, it is the research notebook view:
plans, checksums, computed statistics, findings, tables, and figure-ready data.
The complete scientific artifacts remain in Cognityx Storage.

```text
Cognityx component publications in Storage
                    ↓ whitelisted snapshot
          cognityx-experiment-results
                    ↓
       human review and paper preparation
```

## Public-data warning

Everything committed here is public. Never add secrets, credentials,
environment variables, private source documents, personal data, model weights,
adapters, checkpoints, raw PDFs, MLflow databases, full telemetry streams,
user-home paths, or temporary-directory paths. The publisher uses an explicit
whitelist and sanitized content policy by default, but human review remains
required.

This bootstrap contains no synthetic or real scientific result.

See [SCHEMA.md](SCHEMA.md) for immutable snapshot and journal conventions.
